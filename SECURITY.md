# Security Policy

## Supported versions

The project currently supports the latest version on the default branch.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues or pull requests.

Instead, use one of the following options:

- open a private GitHub Security Advisory for this repository, if available
- contact the maintainers directly through the repository's private reporting channel

Please include as much detail as possible:

- description of the vulnerability
- affected version or commit
- steps to reproduce
- potential impact
- suggested mitigation if known

We will do our best to confirm and address the issue promptly.
